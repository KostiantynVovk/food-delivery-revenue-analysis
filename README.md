# Food Delivery Revenue Analysis

## Project Overview
This project analyzes a dataset of ~10,000 food delivery orders to identify operational inefficiencies and revenue loss. Using **PostgreSQL**, I performed data cleaning, identified voucher discrepancies, and implemented customer segmentation.

## 💰 Key Business Impact:
- **Identified $28,500 in annual revenue leakage** due to incorrect voucher applications.
- **Segmented 1,000+ customers** into Gold/Silver/Bronze tiers for targeted marketing strategies.
- **Improved data quality** by standardizing regional delivery metrics.

## 🛠 Tech Stack:
- **Language:** SQL (PostgreSQL)
- **Analytics:** Data Cleaning, RFM Analysis (Segmentation), Revenue Tracking
- **Visualization:** Google Sheets & Notion

## 📂 Project Structure:
- `/scripts`: Contains the SQL queries used for analysis.
- `/data`: Sample dataset (or data schema description).
- `/visuals`: Charts and dashboard screenshots.
