# Dataset Description

This project uses a food delivery dataset with ~10,000 orders.

## Main table: `food_delivery`

Key fields used in the analysis:
- `order_id` — unique order identifier
- `order_status` — completed or cancelled
- `weather_precipitation` — precipitation level
- `delivery_duration_actual` — actual delivery time
- `delivery_duration_estimated` — estimated delivery time
- `customer_loyalty_tier` — Bronze / Silver / Gold
- `discount_code` — applied promo code
- `discount_type` — fixed amount / percentage / free delivery
- `total_amount` — order value
- `delivery_fee` — delivery fee

## Notes
- Dataset used for educational and portfolio purposes
- Analysis performed in PostgreSQL
- Visuals created in Tableau
